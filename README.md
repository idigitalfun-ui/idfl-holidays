# IDFL Staff Holidays & Hours Tracker

Official IDFL Staff Holiday Balance & Timesheet Portal.

- Multi-year connected holiday tracking (2024, 2025, 2026)
- 8% holiday accrual on worked hours
- 35 hours / year sick leave tracking
- Personal staff portal window for phone and PC
- Worked hours for 2025 and 2026 reconciled against the weekly-hours source

If a browser shows **Sync paused**, use **Sync & Backup**, download a backup if needed, then choose **Use Latest Shared Record on This Device**. This safely replaces that browser's old unsent copy with the current shared company record.
